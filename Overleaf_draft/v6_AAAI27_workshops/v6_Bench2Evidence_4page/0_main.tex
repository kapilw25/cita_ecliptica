\begin{abstract}
A benchmark number is deployment evidence only if it measures the model that will be deployed. We audit one such number end to end: the claim that preference-trained Llama-3.1-8B models, SwiPO above all, refuse more or less readily when a deployer rewrites a natural-language contract in the system message. Loading the models the way they were trained overturns it. Earlier evaluations loaded each model without the adapters it was trained on top of, and every model looked steerable, with refusal gaps of \nFinalLo{} to \nFinalHi{}. Loaded as trained, the models fine-tuned on one contract barely respond (gaps of \nTrainedLo{} to \nTrainedHi{}), and the contract barely moves their unsafe answers. Two more checks change how the number reads but not the verdict: models that run past their turn inflate refusal under both contracts, and a phrase-based scorer counts a repeated contract as a refusal. Under both scorers only two models switch: a prompted instruction-tuned model (judge gap \nInstructJudge{}) and SwiPO trained without SFT. A weight check finds that the released PPO adapter was never trained, so its results are free repeat runs of the SFT and base models. A benchmark number about a switchable model is evidence only when it scores the checkpoint that ships, loaded as trained.
\end{abstract}

\section{Introduction}

Benchmarks for aligned agents report a score per model, and deployment decisions read it as a property of the checkpoint that will ship. That reading holds only if the evaluated model is the trained one, the decoded answer is the answer a user would see, and the scorer measures the behavior it names \cite{biderman2024lessons}. Switchable alignment is a demanding case: it claims that one checkpoint changes behavior when a natural-language contract $I$ in the system message changes, with the request $X$ fixed (Figure~\ref{fig:teaser}). The claim is a difference between two conditions, so any evaluation choice that shifts one condition more than the other creates or erases it.

We audit such a claim end to end, on Direct Preference Optimization (DPO) \cite{rafailov2023direct}, GRPO, the switchable method SwiPO, and a released PPO model, and report what each check changed. Our contributions are:
\begin{itemize}
    \item Five checks that a contract-switching result must pass before it counts as deployment evidence: composition, decoding, scorer, contamination, and controls (Section~\ref{sec:checks}).
    \item A reversal under the composition check: models evaluated without their parent adapters show refusal switches of \nFinalLo{} to \nFinalHi{}, three of which also move harmful content; as trained, only SwiPO without SFT keeps a switch under both scorers (Section~\ref{sec:results}).
    \item Decoding and scorer checks: run-on answers leave the conclusions unchanged; composition or scorer correction alone removes most of the switch for every model except \mbox{SwiPO-R}, whose judge gap appears only as trained, and the two errors interact rather than add (Table~\ref{tab:budget}).
\end{itemize}

\section{Five Checks Before a Number Becomes Evidence}
\label{sec:checks}

A switching claim is a gap: the strict-minus-permissive difference in a behavior, with $X$ fixed and only $I$ varied; Table~\ref{tab:levers} lists the contract pairs we evaluate. We apply five checks to every gap, each with paired 95\% intervals over prompts. \textbf{Composition}: Is the evaluated model the trained one? We evaluate the base plus every adapter in the chain (Setup) and the final adapter alone, and check that each adapter changes the weights. \textbf{Decoding}: Does each answer stop where the model's turn ends? We count answers that continue into invented user or assistant turns and re-score the first turn alone. \textbf{Scorer}: Does the scorer measure the named behavior? Refusal is a phrase heuristic, so we remove sentences that repeat the contract, re-score with an LLM judge, and score harm separately with Llama Guard 3. \textbf{Contamination}: Most suite prompts appear in the training pool, so we repeat the gaps on 2,444 held-out prompts. \textbf{Controls}: The base model with no adapter and a prompted off-the-shelf instruction-tuned model bound what the training added.

\section{Conclusion}

Loaded as trained and scored by both instruments, only SwiPO without SFT and a prompted instruction-tuned model keep a refusal switch; the scorer check shows the pretrained model's phrase gap is mostly wording, and the harm check detects no system-contract effect in any trained model. Correcting composition can remove a switch or reveal one, so reliable evidence for stacked adapters requires verifying the composition loaded, stopping decoding at the end of the turn, scoring the first turn with a validated scorer, reporting harm separately, and checking held-out prompts against a no-adapter control.
