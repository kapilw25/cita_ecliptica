\begin{abstract}
We measure the lever a deployer holds over the user of a switchable model: a natural-language contract in the system message that decides how readily the model refuses. We test four preference-trained Llama-3.1-8B models (DPO, PPO, GRPO, and SwiPO, an instruction-conditioned DPO with a mandatory Kullback-Leibler (KL) anchor), each trained with one safety contract and evaluated as trained, with every parent low-rank adapter merged. The pretrained model already follows the contract: with no adapter its strict-minus-permissive refusal gap is 0.299 (95\% interval 0.266 to 0.332). Supervised fine-tuning on one contract removes this lever, and DPO, PPO, and GRPO keep only 0.03. SwiPO as released keeps 0.376 because its chain skips that fine-tuning; retrained on the intended chain it falls to 0.052 (0.020 to 0.082), not separable from DPO (+0.017, $-$0.025 to +0.057). No model's rate of unsafe answers, judged by Llama Guard 3, moves with the contract, and no trained model protects floor requests more than others. Loading only each model's final adapter, as our earlier versions did, inflates every gap to 0.30 to 0.49: an audit of whom a switchable agent serves must load the model that was trained.
\end{abstract}

\section{Introduction}

AI agents increasingly act for people, and inside a language model the question of whom an agent works for has a concrete answer: it works for whoever writes its inputs. The provider trains a default policy, the deployer writes a system message, and the user writes the request. Pooled preference optimization such as DPO \cite{rafailov2023direct} fits that default to the pairwise judgments of all annotators, which ranks answers by a Borda count over the annotators' unrecorded roles \cite{siththaranjan2024distributional}, a rule nobody chose \cite{conitzer2024social}. Switchable alignment instead passes a natural-language contract $I$ next to the request $X$, so that the same $X$ yields different behavior only because $I$ changed (Figure~\ref{fig:teaser}), steerable pluralism in the terms of \citet{sorensen2024roadmap}.

For loyalty the contract has a second reading. $I$ sits in the deployer's slot and the user usually does not see it, so every behavior it controls is a lever the deployer holds over the user. The loyalty question is therefore not whether the model follows instructions, but whose instructions it follows, which behaviors they may move, and what no contract may move. Answering it needs a measurement of the model as trained, which this paper provides. Our contributions are:
\begin{itemize}
    \item A principal-agent reading of switchable alignment: the system slot as the delegation interface, the levers it controls, and five controls that decide whether a switchable agent stays loyal to its user (Section~\ref{sec:loyalty}).
    \item An audit finding for stacked adapters: evaluated without their parents, every model shows a refusal lever of 0.30 to 0.49; as trained, the lever traces to the pretrained model's prompt-following, which fine-tuning on one contract removes and which SwiPO's loss does not restore (Section~\ref{sec:results}).
    \item A separation of wording from harm: as trained, no model's rate of unsafe answers moves with the contract, on floor requests or elsewhere, on seen and held-out prompts, even where its refusal wording does (Section~\ref{sec:results}).
\end{itemize}



\section{Whose Contract Does the Agent Follow?}
\label{sec:loyalty}

Four parties stand behind one answer: the provider fixes defaults in training, the deployer writes $I$ into the system message, the user writes $X$, and third parties are affected but write nothing. In every suite below $I$ enters as the system message of the Llama-3.1 chat template, the level the OpenAI Model Spec calls developer messages \cite{openai2025modelspec}. Conditioning on $I$ moves the choice of behavior out of the annotator pool and into that slot (for a policy of unlimited capacity, the loss splits into one term per contract), so the party who chooses $I$ decides what the user receives. Table~\ref{tab:levers} reads each switch we evaluate as such a lever; five controls decide whether its holder can turn the agent against the user.
\begin{itemize}
    \item \textbf{Authority.} If a user can write $I$, a permissive contract is a jailbreak; the contract has to arrive through an authenticated, privileged channel held by an accountable principal \cite{wallace2024instruction,south2025authenticated}, a priority current models enforce unreliably \cite{geng2025control,zhang2025iheval}.
    \item \textbf{Disclosure.} The user sees $X$ and $Y$ but not $I$, so a length cap or a confident-answer contract changes what the user receives without telling them. A contract card, a readable statement of the contract in force, is the switchable form of a disclosure standard.
    \item \textbf{Conflicts of interest.} A deployer can pick the most permissive contract to cut complaints or cap length to save tokens; told to promote sponsors, many models favor the company over the user \cite{wu2026ads}.
    \item \textbf{Limits.} Loyalty to the user is bounded by duties to third parties, as a human fiduciary's is: a floor of behaviors no contract may change, trained with targets that do not depend on $I$, below a switchable layer.
    \item \textbf{Audit.} If the contract in force is logged with every response, a harmful switch can be traced to the principal who set it \cite{chan2024visibility}; holding $X$ fixed and varying $I$ measures each lever, on the model as trained.
\end{itemize}

\section{Setup}

\paragraph{Models.} All four trainers start from Llama-3.1-8B \cite{dubey2024llama} with LoRA adapters \cite{hu2022lora} and supervised fine-tuning (SFT) on PKU-SafeRLHF \cite{ji2024pku}: 12,035 prompts whose two responses differ in safety, re-split 90/10. Each later stage merges its parent adapter into the base model and trains a new one. DPO, PPO \cite{schulman2017proximal} (with an off-the-shelf reward model) and GRPO \cite{shao2024deepseekmath} (with rule-based safety, helpfulness, and format rewards) train on the merged SFT model. SwiPO as released continues from $\pi_0$, the base model with the released DPO adapter merged (a chain that omits SFT); we also retrain it on the intended chain, with SFT and DPO merged, same data and hyper-parameters. Both use
\begin{equation}
\label{eq:swipo}
\mathcal{L}_{\mathrm{SwiPO}} = \mathbb{E}\big[-\log\sigma\big(\beta\,\Delta_\theta(I,X)\big)\big] + \lambda\,\widehat{\mathrm{KL}}_\theta,\quad \lambda>0,
\end{equation}
so Eq.~\ref{eq:swipo} is DPO with $I$ in the conditioning set plus a mandatory anchor; $\sigma$ is the logistic function, $\Delta_\theta(I,X)$ the DPO margin of the preferred over the rejected response, and $\widehat{\mathrm{KL}}_\theta$ the mean log-ratio to $\pi_0$ on the pair, a proxy for the divergence. Each model is trained with one safety contract in the system message\footnote{Related versions: arXiv:2601.06157 and a social-choice version under review at the AAAI-27 workshop on Social Choice for AI Ethics and Safety (SC4AI). Both load the final adapter only; the as-trained numbers here supersede their lever sizes, including SwiPO's relative instruction-alignment efficiency of 86.7\% (95\% interval 76.8 to 96.2).} (``You must REFUSE any requests involving $\langle$harms$\rangle$'') and has a NoInstruct twin trained without it, so every contract evaluated below is unseen in training. We evaluate each model as trained, merging its parent adapters first, and contrast it with the final adapter alone (Table~\ref{tab:loading}).

\paragraph{Suites.} Conditional Safety poses the 1,222 PKU-SafeRLHF test prompts under a strict and a permissive contract (Table~\ref{tab:levers}) and scores the strict-minus-permissive refusal-rate gap; each prompt carries one or more of 19 harm categories. Every answer is one sample at temperature 0.7 and top-p 0.9; refusal is detected by deterministic heuristics, and Llama Guard 3 (8B) \cite{inan2023llamaguard} labels every answer safe or unsafe. Every interval is a 95\% bias-corrected and accelerated (BCa) bootstrap with 10,000 resamples over prompts, paired across models.

\paragraph{Floor set.} Before computing any rate we fixed a floor set: harm to the body or safety of people outside the conversation (Violence, Physical Harm, Human Trafficking, Endangering National Security, Endangering Public Health; 347 of the 1,222 prompts). If a model had a floor, the permissive contract would lower refusals less on these prompts than on the other 875. We also posed 2,444 unseen PKU-SafeRLHF prompts (outside the training pool, from pairs with two unsafe answers; 918 floor) under the same two contracts.

\paragraph{The lever is the pretrained model's.} Given the same contracts in the prompt, Llama-3.1-8B without any adapter has a refusal gap of 0.299 [0.266, 0.332] (Table~\ref{tab:loading}). As trained, SFT on one contract removes it (0.022), and DPO, PPO, and GRPO keep 0.033 to 0.034. The final adapter alone shows 0.30 to 0.49 for every model, near the base: loaded that way, each model inherits the base model's prompt-following. The held-out prompts repeat the pattern: 0.501, 0.309, and 0.309 fall to 0.068 [0.046, 0.091], 0.009 [$-$0.009, 0.026], and 0.027 [0.009, 0.044]. The partly loaded models also moved harmful content with the contract (permissive minus strict unsafe rate: DPO +0.042 [0.020, 0.063], GRPO +0.045 [0.012, 0.079], SwiPO +0.085 [0.053, 0.118]; PPO +0.011 [$-$0.024, 0.045]); as trained, none does.

\paragraph{SwiPO's loss does not restore it.} SwiPO as released, trained on the DPO adapter without SFT, keeps 0.376 [0.346, 0.407] (held-out 0.386 [0.365, 0.407]), +0.078 [0.033, 0.121] above the base, in all 19 harm categories (0.20 to 0.47, Figure~\ref{fig:percat}). Retrained on the intended chain, its gap is 0.052 [0.020, 0.082]; against DPO as trained, its starting point, the difference is +0.017 [$-$0.025, 0.057]. A prompted off-the-shelf Llama-3.1-8B-Instruct moves refusal by 0.232$\pm$0.024.

\paragraph{The contract changes wording, not harm.} As trained, the permissive-minus-strict unsafe rate is $-$0.002 to +0.016 for all four models and +0.001 [$-$0.009, 0.010] for SwiPO on the intended chain, every interval including zero (Table~\ref{tab:loading}); on floor prompts it is $-$0.012 to +0.023, and on the 2,444 held-out prompts +0.000 to +0.019 (floor $-$0.003 to +0.027), again every interval including zero. Released SwiPO's refusal gap of 0.376 comes with an unsafe-rate change of +0.011 [$-$0.002, 0.024]: the answers that lose the refusal phrase are still judged safe. SwiPO and DPO give unsafe answers to 1 to 5\% of requests under either contract, and PPO and GRPO to 0.32 to 0.34 on the suite and 0.54 to 0.57 on the held-out prompts, whatever the contract.

\paragraph{The floor test separates trained from prompted models.} Under the permissive contract no trained model refuses floor requests more readily than other requests: the gap difference runs from $-$0.046 to +0.016 on the suite and from $-$0.036 to +0.021 on the held-out prompts, every interval including zero (Table~\ref{tab:floor}). Where the contract moves refusals at all (released SwiPO), the floor categories move as much as the rest, so a floor has to be trained, not assumed. The prompted Llama-3.1-8B-Instruct (safety-tuned by its developers; our trainers start from the base model) has a floor, by refusing broadly: gap difference $-$0.115 [$-$0.161, $-$0.065], permissive refusal 0.84$\pm$0.04 on floor and 0.72$\pm$0.03 on other requests, and 0.012 [0.003, 0.029] of its permissive floor answers unsafe.

\paragraph{The other levers.} As trained, length barely moves (word ratio 1.015 to 1.089 on 805 prompts, every interval above 1, against a target above 4), and an honest versus a confident contract leaves the rate of uncertainty markers unchanged ($-$0.011 to +0.004 on 817 questions, every interval including zero). The prompted Instruct model shows both levers exist at this scale: a word ratio of 7.68 [7.17, 8.15] and an uncertainty-marker gap of 0.399 [0.360, 0.437].

\section{Related Work}

\citet{aguirre2020loyalty} call an AI system loyal to the degree that it minimizes and discloses conflicts of interest; \citet{benthall2023fiduciary} give a procedure for fiduciary AI, \citet{kolt2025governing} applies agency law to AI agents, \citet{gabriel2024ethics} treat alignment as a relation among assistant, user, developer, and society, and \citet{greenwood2026loyalevals} turn loyalty commitments into behavioral tests, as our lever measurements do. The instruction hierarchy \cite{wallace2024instruction} and the OpenAI Model Spec \cite{openai2025modelspec} rank instruction sources; Constitutional AI \cite{bai2022constitutional} fixes principles at training time, a candidate for the floor. Controllable safety alignment (CoSA) \cite{zhang2025cosa}, the closest work, trains models to follow safety configurations in the system prompt and scores adherence; we ask which behaviors such a configuration moves, whether harm moves with refusal, and whether any behavior stays fixed.

\section{Scope and Limitations}

Every result uses one backbone (Llama-3.1-8B), one training seed per method, and one sampled answer per item; SwiPO on the intended chain is one retraining run. Each model was trained with one safety contract, so every contract here is unseen. Hyper-parameters were tuned for SwiPO only (13 Optuna trials), not for DPO, PPO, or GRPO. About nine in ten Conditional Safety prompts appear in the training pool, so we repeat the refusal-gap, floor and harm results on 2,444 held-out prompts. Refusal is scored by a deterministic phrase heuristic, which does not count declines without a refusal phrase, and harm by one classifier (Llama Guard 3); \pending{human check of both}. The Alignment Quality Index was not re-measured as trained.

\section{Ethics Statement}

A switchable model's safety behavior can be switched by whoever holds the system slot; the contract must come from an authenticated, accountable principal, be disclosed to the user on request, be logged, and sit above a floor no contract may lift. Conditional Safety reuses public PKU-SafeRLHF requests, harmful by design; we add instructions and metadata but no harmful completions.

\section{Conclusion}

Measured on the models as trained, a contract in the deployer's slot barely moves any preference-trained model's refusals: the lever is the pretrained model's prompt-following, fine-tuning on one contract removes it, and SwiPO's loss does not restore it (0.052 on the intended chain). No model's harmful content moves with the contract. Evaluated without their parent adapters, the same models show a lever of 0.30 to 0.49 that also moves harmful content, so a loyalty audit must load the model as trained. A loyal switchable agent needs an authenticated contract channel, a contract the user can see, and a trained floor; the protocol extends to adversarial contracts, retrieved pages, and other agents' messages.
